# Bank Loan Analysis Dashboard

## Project Overview

This project is an interactive Bank Loan Analysis Dashboard built using SQL and Power BI. The dashboard analyzes loan applications, funded amounts, repayments, borrower profiles, and loan performance to generate business insights and monitor portfolio health.

---

## Tools & Technologies

- SQL (MySQL)
- Power BI
- Power Query
- DAX

---

## Dashboard Pages

### 1. Summary Dashboard
- Total Loan Applications
- Funded Amount
- Amount Received
- Average Interest Rate
- Good vs Bad Loan Analysis
- Loan Status Summary

### 2. Overview Dashboard
- Monthly Funding Trends
- Loan Purpose Analysis
- Loan Term Distribution
- Employee Length Analysis
- State & Grade Filters

### 3. Details Dashboard
- Loan-level transactional data
- Borrower details
- Funded amount and repayment tracking

---

## Key Insights

- Majority of loans belong to the Good Loan category.
- Debt consolidation is the most common loan purpose.
- Long-term loans contribute significantly to funded amounts.
- Loan applications and funded amounts show a consistent upward trend.
